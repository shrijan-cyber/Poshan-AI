# Taste Skill: selective Food Library UI changes

The project-local Taste Skill guidance was applied to the catalog detail hierarchy: recognizable macro summary first, additional nutrients grouped below, clear data provenance and missing/unit uncertainty directly beside values. Existing forest/sage/paper styling, reusable card patterns, responsive grid and keyboard-operable expansion remain intact. No external skill scripts, image assets, fonts or dependencies were added.

Food photography is deferred. No image in the current catalog has an exact food identity, raw/cooked match, source license and attribution record. Placeholder or unrelated photos would misrepresent composition. Add images only after per-asset license/attribution and state checks, store image provenance, optimize and lazy-load them, and retain a meaningful no-image fallback.

The product already has a rich Food Library layout; this sprint changes information hierarchy and honest nutrient detail rather than performing a broad redesign of other routes.
