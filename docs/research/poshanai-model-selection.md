# PoshanAI model selection and task routing

**As of:** 5 November 2026. This is a selection policy, not an enabled production configuration. Provider quotas, models, terms and capabilities drift; recheck official sources and project-level quotas before use.

## Candidate policy

The only candidate with currently verified first-party model facts in this audit is Google Gemini API. The source code’s current model value `gemini-2.0-flash` is listed as shut down and must not be treated as a viable current candidate. Google currently lists Gemini 3.8 Flash (`gemini-3.8-flash`) and Gemini 3.1 Flash-Lite (`gemini-3.1-flash-lite`) as stable model IDs; structured output is supported by documented Gemini API models, but exact capability should be checked for the selected model. Google publishes free and paid price tiers; free-tier submitted content may be used to improve products, while paid-tier content is not, per pricing docs. Rate limits depend on project/tier and must be checked in AI Studio; they are not a universal static quota. [Models](https://ai.google.dev/gemini-api/docs/models), [pricing](https://ai.google.dev/gemini-api/docs/pricing), [rate limits](https://ai.google.dev/gemini-api/docs/rate-limits), [structured output](https://ai.google.dev/gemini-api/docs/structured-output)

## Candidate comparison

- **Gemini 3.8 Flash (`gemini-3.8-flash`):** preferred benchmark candidate for short recipe-language tasks because Google currently describes it as a stable Flash model and publishes free/paid API pricing. Free is not suitable for confidential inputs based on the pricing page’s data-use notice. Exact latency and context must be obtained from current model details/benchmark; no measured result exists here.
- **Gemini 3.1 Flash-Lite (`gemini-3.1-flash-lite`):** lower-cost candidate for small formatting tasks. Published paid input price is lower than Gemini 3.8 Flash at time checked, and free tier is listed. Needs quality comparison; do not presume parity for instruction quality or schema compliance.
- **Existing `gemini-2.0-flash`:** reject as current configuration: Google marks it shut down. Migrate only through a separately approved config change after checking upstream gateway’s supported model IDs.
- **Other free API directory models:** discovery only. Do not add a provider until official API format, quotas, data retention, terms, region and schema/tool behavior are independently checked. No candidate is approved to receive personal/health data.

## Model evaluation gates

Use a fixed, synthetic set of recipe templates and measure p50/p95 latency, success rate, retry count, valid JSON, schema pass rate, added-ingredient violation rate, static fallback rate, reported tokens and provider-reported cost. Provider cost should be `unknown` if no reliable price/usage is returned. Set acceptance thresholds before a live call; the current POC is mocked and supplies no empirical scores. Never score nutrition values generated by a model: nutrition remains deterministic backend output.
