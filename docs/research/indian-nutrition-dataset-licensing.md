## Required approval packet before any food-data promotion

For each source and dataset version, record the license text/URL, source organization, upstream sources, redistribution and commercial-use rights, attribution text, share-alike obligations, allowed transformations, exact source identifier, source row locator, capture timestamp, content checksum, unit/basis mapping and raw/cooked state. Have counsel or the data owner resolve ambiguity. A repo's code license does not automatically license bundled data.

Until approved, external data stays under `data/staging/`, source-separated, `productionImport: false`, and cannot affect search, meal selection, or macros. Do not infer permission from an API being reachable or a data file being public.
